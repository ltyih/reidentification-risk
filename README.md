**Quantifying Re-Identification Risk in Child Health Data**

**Proposed by:** The One Child Every Child (OCEC) Data Accelerator

# Project Summary

A pipeline for the generation of reports identifying the re-identification risk (RR) of clinical datasets under a variety of RR measures. The provided measures are:

- Single set measures:
    - $k$-anonymity
    - Entropy

- Double set measures:
    - Probabilistic $k$-anonymity
    - Cross-entropy
    - Benedetti-Franconi

- ID data generation:
    - Gaussian copula
    - Bayesian networks
    
- RR field ranking:
    - Discrimination rate
